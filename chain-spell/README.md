# Chain Spell

A word-chain typing game. Type a word — the next word must start with the last letter of the previous one. How long can you keep the chain alive?

## How to play

- Type any word to begin
- Each new word must start with the last letter of the previous word
- You have a timer. Each accepted word resets it and adds bonus time (longer words = more time)
- The timer ceiling tightens every 5 words (one level)
- Run out of time and it's game over

## Scoring

- **10 points per letter** in the accepted word
- **Combo multiplier** — type 3 or more consecutive words of 6+ letters to stack a ×1.5, ×2.0, … ×4.0 multiplier

## Hard Mode

Check the **HARD MODE** box before starting. A random forbidden letter is set each level — any word containing that letter is rejected.

## Play

Open `game.html` in any browser. No server required.
